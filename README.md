# 🌐 ELACSTA - Official Club Website

Welcome to the official website of **ELACSTA**, the Electronics and Communication Student Technical Association of NSS College of Engineering, Palakkad.

This project is built with **React + Vite**, showcasing the club's vision, team, events, blog posts, and media gallery — all wrapped in a responsive and futuristic design.
